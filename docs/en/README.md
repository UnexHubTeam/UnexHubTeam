Check [protocol compatibility](compatibility.md) before choosing a tool and endpoint. PoloAPI pages and the listed official/project references were reviewed. No installation commands, client configuration changes, or paid model requests were executed. Messages, Responses, CC MAX, and native editor gateway support are qualified according to the available evidence.

Console screenshots show the Chinese interface; each English page independently explains the corresponding steps. Verify current model IDs, versions, prices, and routing when using the service.
